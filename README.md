# זירת האלופים

[**הורדת המשחק — ZIP**](https://github.com/galitcohen99-crypto/-/raw/refs/heads/codex-wrestling-game/game.zip)

הורד את ה־ZIP, חלץ אותו ופתח את `index.html` בדפדפן.

עותק פתיחה נמצא גם ב־`index.html` בשורש המאגר.

הגרסה הפעילה: **`output/zirat_haalufim_v32.html`**. קובץ עצמאי בעברית, ללא צורך בהתקנה או ברשת. יש גם ZIP לצד הקובץ. זו גרסה עם איורים ריאליסטיים ואנימציית תמונות דו־ממדית, עם תנועה ועומק; אין בה מודלים תלת־ממדיים פוטוריאליסטיים.

שליטה ביד שמאל: ש/ג לתנועה, רווח לקפיצה, כ לאגרוף, ק לבעיטה, ר להטלה, שיפט שמאלי לחסימה, ב למהלך סיום, ה להצמדה. גם החצים פועלים. בפריסה אנגלית: A/D לתנועה, F אגרוף, E בעיטה, R הטלה, Shift חסימה, C מהלך סיום, V הצמדה. מקש הרווח שוב ושוב להיחלצות. אותם מיקומים עובדים בפריסה אנגלית. כפתורי מגע מתחת לזירה. תוצאות נשמרות מקומית בדפדפן. כרגע קרב אחד בין קייזר לבריון וארבע רמות קושי.

להרצה מקומית:

```sh
python -m http.server 8000 --directory output
```

## קוד וגרפיקה

- `src/cinematic.html` — מבנה המשחק והממשק.
- `src/cinematic.css` — עיצוב הממשק.
- `src/cinematic-game.js` — מנגנון הקרב, הבינה המלאכותית, שליטה, ציור ואפקטים.
- `assets/` — גרפיקה ייעודית שנוצרה באמצעות כלי יצירת התמונות של OpenAI: שני גיליונות תנוחות, גיליון הליכה ורקע זירה. קובצי המקור נשמרים ללא שינוי.
- `tools/atlas_geometry.py` — קורא את השקיפות ומחשב גאומטריית חיתוך לציור דמות בלי שברי דמויות סמוכות. אינו משנה את התמונות.
- `tools/build_cinematic.py` — מטמיע את כל הקוד והתמונות בקובץ HTML יחיד ויוצר ZIP.

לפתיחה: הורד את ה־ZIP, חלץ אותו ופתח את `index.html` בדפדפן. תצוגה מקדימה בצ׳אט אינה בדיקת הפעלה של המשחק. גרסה 32 כוללת את כל הנכסים בפורמט WebP בתוך ה־HTML: כ־2.07MB לקובץ וכ־1.55MB ל־ZIP.

לבנייה מחדש נדרשים Python ו־Pillow בלבד:

```sh
python tools/build_cinematic.py
```

בדיקות בדפדפן משתמשות ב־Playwright וב־Chromium. `window.arenaSnapshot()` מחזיר צילום מצב לקריאה בלבד לצורך בדיקות. ניתן לשלוט בעזרת מקשים ואירועי מגע; אין ממשק לשינוי מצב פנימי דרך הבדיקות.

הגרסאות הקודמות נשמרו לעיון. גרסה 28 היא ניסוי התלת־ממד הקודם ואינה הגרסה הפעילה.


המרת PNG ל־WebP בוצעה באמצעות FFmpeg (איכות 90, אותן מידות ושקיפות). נכסי PNG המקוריים נשמרו. בדיקת מסירה: חלץ את ה־ZIP לתיקיית בדיקה, הגש אותה בשרת מקומי והרץ `node tools/smoke_release.cjs http://localhost:8001/index.html`. הבדיקה עוברת למצב לא מקוון לאחר הטעינה ומאמתת תנועה, נזק, מקלדת בעברית, השהיה ומגע.


גרסה 32 מוסיפה הקלטת המולת קהל, תגובות עידוד ומחיאות כפיים, קולות אנושיים לפגיעות, אפקטים נפרדים לחסימה/מכה/הטלה, וצלצול פעמון. הקול מתחיל אחרי לחיצה על התחלת הקרב. כפתור הצליל משתיק גם קהל וגם אפקטים; בהשהיה הקול מושתק. `src/arena-sound.js` מטפל במיקס ובהגבלת עוצמת פסגות. ההקלטות מקורן ב־0 A.D. של Wildfire Games וברישיון CC BY-SA 3.0; פירוט ומקור ב־`assets/audio/CREDITS.txt` ועותק רישיון ב־`assets/audio/source/LICENSE.txt`. קולות הכאב קוצרו ונוסף להם fade, והמולת הקהל סוננה והומרה ל־MP3. האפקטים וההקלטות מוטמעים בקובץ ופועלים ללא רשת.
